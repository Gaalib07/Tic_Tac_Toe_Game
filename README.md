# 🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript. The game provides a clean user interface and allows two players to compete against each other on a 3×3 grid.

## ✨ Features

- Interactive 3×3 game board
- Two-player gameplay
- Automatic win detection
- Draw detection when all cells are filled without a winner
- Game status updates
- Restart functionality
- Simple and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling and layout
- **JavaScript** – Game logic and interactivity

## 🎯 How to Play

1. Player 1 uses **X**, and Player 2 uses **O**.
2. Players take turns selecting an empty cell.
3. The first player to get three matching symbols horizontally, vertically, or diagonally wins.
4. If all nine cells are filled and neither player wins, the game ends in a draw.
5. Restart the game to play again.
